# Projeto de Análise de Vendas

## Sobre o projeto

Este projeto foi desenvolvido em Python para analisar dados de vendas.

## Análises realizadas

- Cálculo do total de vendas
- Identificação do produto com maior venda
- Total de vendas por região
- Porcentagem de vendas por região

## Resultados

- Total de vendas: R$ 27.900
- Produto com maior venda: Monitor
- Maior venda: R$ 12.600
- Sudeste: 90,54%
- Sul: 9,46%

## Tecnologias utilizadas

- Python
- Visual Studio Code
